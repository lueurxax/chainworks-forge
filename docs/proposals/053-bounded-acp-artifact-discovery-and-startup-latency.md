companion relationship.\n\n### Settlement Boundary\n\nName the Phase 1 settlement entry point `settle_agent_outputs_from_discovery_decisions`.\n\nResponsibilities:\n\n- Accept `agent_execution_id`, discovery_generation_id)` and generation keys for accepted artifact payloads.\n- On retry with the same idempotency key, return the existing settlement result without re-reading target paths.\n- On
