Guardrails

  • No SwiftData, local recovery services, local artifact file scans, or MCP from governed UI.
  • Artifact markdown/json rendering needs server-owned payload readback; metadata-only rows stay visibly unavailable.
  • Any missing GraphQL field becomes an explicit disabled/deferred state, not a local fallback.
