# UI Review Rubric: Apple Liquid Glass Perspective

Evaluate proposal or code-mapped visual design quality as a senior Apple-caliber UI designer. Work from proposal states, adjacent docs, the reusable baseline when present, and current repo surfaces first; use runtime evidence only when it materially clarifies host-system reality.

## Focus Areas

1. Visual hierarchy and clarity
- Check information prominence, grouping, and scanability.
- Verify primary actions remain obvious in dense financial views.

2. Liquid Glass material use
- Evaluate translucency, blur, depth layering, and contrast integrity.
- Ensure glass effects improve comprehension, not decoration-only noise.

3. Typography and iconography
- Verify semantic type scale, weight hierarchy, and readability.
- Ensure icon use is consistent, legible, and action-distinct.

4. Color and semantic tokens
- Validate tokenized color usage for states such as gain, loss, warning, and error.
- Ensure sufficient contrast across light and dark contexts.

5. Motion and transitions
- Evaluate motion purpose, continuity, and perceived performance.
- Ensure transitions communicate state change and preserve orientation.

6. Platform fidelity
- Check alignment with Apple HIG expectations and native affordances.
- Flag custom visual patterns that reduce platform trust.

## Output Requirements

For each finding, include:

- Finding ID
- Severity
- Evidence IDs
- Rationale / Why it matters
- Recommended fix
- Acceptance criteria
- Confidence
